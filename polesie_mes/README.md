# PolesieMES - Система управления производством
## ОАО "Полесьеэлектромаш"

### Описание проекта

**PolesieMES** - это полноценная система управления производством (MES - Manufacturing Execution System), разработанная для ОАО "Полесьеэлектромаш" (Республика Беларусь).

Система предназначена для автоматизации и контроля всех этапов производства электротехнической продукции: от получения заказа до отгрузки готовой продукции.

---

### 🚀 Основные возможности

#### 1. **Управление заказами**
- Создание и редактирование заказов клиентов
- Отслеживание статусов заказов в реальном времени
- Управление приоритетами и сроками выполнения
- Контроль состава заказов

#### 2. **Производственное планирование**
- Планирование производственных заданий
- Распределение задач по этапам производства
- Назначение исполнителей
- Контроль сроков выполнения

#### 3. **Контроль качества (ОТК)**
- Многоуровневый контроль качества
- Фиксация дефектов и несоответствий
- Ведение журналов проверок
- Фотофиксация результатов

#### 4. **Складской учёт**
- Учёт материалов и комплектующих
- Контроль остатков и минимальных запасов
- Движение материалов (приход/расход)
- Инвентаризация

#### 5. **Управление оборудованием**
- Мониторинг состояния оборудования
- Планирование технического обслуживания
- Учёт простоев и неисправностей

#### 6. **Отчётность и аналитика**
- Оперативные отчёты по производству
- Анализ выполнения планов
- Статистика по браку
- Финансовые показатели

### ⚙️ Установка и настройка

#### 1. Установка XAMPP
1. Скачайте XAMPP с официального сайта: https://www.apachefriends.org/
2. Установите XAMPP в директорию по умолчанию (C:\xampp или /opt/lampp)
3. Запустите Apache и MySQL через панель управления XAMPP

#### 2. Развёртывание базы данных
1. Откройте phpMyAdmin: http://localhost/phpmyadmin
2. Создайте новую базу данных с именем `polesie_mes`
3. Импортируйте SQL-файл: `/workspace/polesie_mes/sql/database.sql`

#### 3. Настройка приложения
1. Скопируйте проект в директорию htdocs XAMPP:
   - Windows: `C:\xampp\htdocs\polesie_mes`
   - Linux: `/opt/lampp/htdocs/polesie_mes`

2. При необходимости отредактируйте файл конфигурации:
   - `/workspace/polesie_mes/config/config.php`

#### 4. Запуск системы
1. Откройте браузер
2. Перейдите по адресу: http://localhost/polesie_mes
3. Войдите в систему используя тестовые учётные данные

### 📊 База данных

Система использует следующую структуру БД:

**Основные таблицы:**
- `users` - пользователи системы
- `employees` - сотрудники предприятия
- `customers` - клиенты
- `orders` - заказы
- `order_items` - состав заказов
- `products` - продукция
- `production_tasks` - производственные задания
- `production_stages` - технологические этапы
- `quality_checks` - проверки качества
- `materials` - материалы
- `material_movements` - движение материалов
- `equipment` - оборудование
- `activity_log` - журнал событий

База данных заполнена тестовыми данными, имитирующими реальную работу предприятия за период 2023-2024 гг.
